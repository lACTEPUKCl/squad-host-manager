Как начать

Для общего хоста попросите владельца дать адрес координатора и приглашение. Зарегистрируйтесь в приложении и запустите свой сервер — новый физический хост арендуется только при отсутствии общего.

Хотите свой аккаунт Cherry Servers?

Создать аккаунт Cherry Servers, затем создайте API Token в настройках портала. Разверните собственный координатор по инструкции на GitHub. Токен хранится у владельца, участникам его передавать не нужно.

Ссылка Cherry Servers является реферальной. Закрытие приложения не прекращает аренду автоматически: выберите действие для своего сервера.
