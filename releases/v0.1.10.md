## ru
Исправлено обновление Squad при ошибках SteamCMD 0x6 и Missing configuration. Перед скачиванием запрашиваются актуальные данные игры, кэш Steam сохраняется между запусками. При отказе в доступе к старому манифесту его метаданные пересоздаются с резервной копией и проверкой файлов. Конфиги серверов сохраняются. В ошибке показывается причина из журнала Steam.

## en
Fixed Squad updates failing with SteamCMD 0x6 or Missing configuration. Game metadata is loaded before downloading, and the Steam cache persists between runs. Revoked old manifests are backed up and rebuilt with file validation. Server configs are preserved. Errors now include the cause from the Steam log.
