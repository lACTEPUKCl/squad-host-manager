## ru
Перед запуском RespawnHost приложение ждёт выделенный порт RCON, задаёт пароль и проверяет сохранённый конфиг. Без успешной проверки игра не запускается. Отказанные заказы больше не оставляют лишние карточки и занятые слоты; история ошибок сохраняется. Новые ошибки аренды показывают причину ответа провайдера без секретных данных. Подходящий выключенный сервер без активной карточки повторно используется только его владельцем. Работающие серверы автоматически не перезапускаются.

## en
Before starting a RespawnHost server, the app waits for an allocated RCON port, sets a password and verifies the saved config. The game is not started if verification fails. Rejected orders no longer leave extra server cards or reserved slots; error history is retained. New rental errors include the provider's reason with secrets removed. A matching offline allocation without a current profile can be reused only by its owner. Running servers are not automatically restarted.

## de
Vor dem Start eines RespawnHost-Servers wartet die App auf einen zugewiesenen RCON-Port, setzt ein Passwort und prüft die gespeicherte Konfiguration. Ohne erfolgreiche Prüfung startet das Spiel nicht. Abgelehnte Bestellungen hinterlassen keine zusätzlichen Serverkarten oder reservierten Plätze; Fehler bleiben im Verlauf. Neue Mietfehler zeigen den Grund des Anbieters ohne geheime Daten. Eine passende ausgeschaltete Zuweisung ohne aktuelles Profil kann nur ihr Besitzer wiederverwenden. Laufende Server werden nicht automatisch neu gestartet.

## es
Antes de iniciar un servidor RespawnHost, la aplicación espera un puerto RCON asignado, establece una contraseña y verifica la configuración guardada. El juego no se inicia si falla la verificación. Los pedidos rechazados ya no dejan tarjetas adicionales ni plazas reservadas; se conserva el historial de errores. Los nuevos errores de alquiler muestran el motivo del proveedor sin datos secretos. Solo el propietario puede reutilizar un servidor compatible apagado y sin perfil actual. Los servidores activos no se reinician automáticamente.

## fr

Les commandes refusées ne laissent plus de fiches supplémentaires ni de places réservées ; l’historique des erreurs est conservé. Les nouvelles erreurs de location indiquent le motif du fournisseur sans données secrètes. Seul le propriétaire peut réutiliser une allocation compatible arrêtée sans profil actuel. Les serveurs actifs ne sont pas redémarrés automatiquement.

## zh-Hans

## tr
